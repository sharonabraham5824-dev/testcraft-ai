# TestCraft AI

TestCraft AI is a QA-focused test design assistant that converts software requirements and user stories into structured test cases with priority, risk level, automation recommendation, testing tool suggestion, QA reasoning, and CSV export.

## Project Overview

TestCraft AI helps QA engineers, automation testers, and business analysts quickly design test cases from requirements.

Instead of only generating generic test cases, TestCraft AI also explains why each test matters and whether it is a good candidate for automation.

## Features

- Generate test cases from user stories
- Generate positive test cases
- Generate negative test cases
- Generate validation test cases
- Generate boundary test cases
- Generate security test cases
- Classify test case priority
- Classify risk level
- Suggest automation suitability
- Recommend testing tools
- Explain why each test case matters
- Display QA summary metrics
- Export test cases as CSV

## Tech Stack

- Python
- Streamlit
- Pandas
